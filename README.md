# NEXTHIRE AI 🚀

> **AI-Powered Talent Intelligence & Recruitment Analytics Platform**

NEXTHIRE AI is a modern, high-performance web dashboard engineered for recruitment teams, talent acquisition leaders, and AI hiring pipelines. It provides real-time visibility into candidate flow, automated screening metrics, and interview sentiment analytics.

---

## ✨ Features

- **📈 Talent Pipeline Analytics**: Smooth bezier canvas-rendered candidate throughput visualization with key weekly benchmark indicators.
- **😄 Candidate Sentiment Index**: Interactive sentiment distribution tracking feedback and experience metrics post-interview.
- **🎯 Milestone Status Tracking**: Granular stage breakdowns from AI Screened, Technical Assessment, to Final Rounds and Offers Accepted.
- **⚡ Live Activity Feed**: Real-time event log for candidate milestone completions and AI evaluation scores.
- **💎 Dark Glassmorphic Interface**: Tailored dark mode aesthetic with custom gradients, micro-interactions, responsive side navigation, and mobile-ready layouts.

---

## 🛠️ Tech Stack

- **Markup & Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Design Tokens, Flexbox, CSS Grid, Glassmorphism)
- **Visuals & Charts**: HTML5 Canvas API (custom smoothed bezier curve rendering)
- **Icons**: [Lucide Icons](https://lucide.dev)
- **Typography**: [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts

---

## 🚀 Quick Start

No dependencies or build steps required. Simply open `index.html` or `frontend/index.html` in any modern web browser:

```bash
# Option 1: Direct open in browser
open frontend/index.html

# Option 2: Run with local HTTP server
npx serve .
# or
python3 -m http.server 3000
```
